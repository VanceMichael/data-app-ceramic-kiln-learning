# 资料契约

所有记录均为本地合成演练资料，不含真实个人、企业或医疗信息。文件使用 UTF-8 JSON，金额和数量以各字段说明为准。空串、零、缺报、争议分别保留其含义，不可互相替换。

记录的 `id` 只在本资料类别内唯一。`known`、`known_day`、`known_week`、`known_month` 表示收到事实的时间；实际发生时间另有字段。日序和分钟是演练的相对时间，未另行说明的区间均左闭右开。月份为演练年度的自然月。

`data/schema.json` 声明字段、类型和显式引用。数组与对象内的业务关系按相应中文字段说明解释；资料检查器不替代这些业务关系的判断。原始与后补记录共存，文件排列不代表业务生效顺序。

## kilns

每窑是独立试烧单位。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 窑次 |
| `planned` | string | 原工艺 |
| `actual` | string | 实际工艺 |
| `density` | number | 装载密度 |
| `energy_kwh` | number | 实耗电量 |
| `material` | string | 材料批 |
| `day` | integer | 烧制日 |

## pieces

坯体实物可以返工；留样不可销售。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 实物 |
| `kiln` | string | 当前窑次 |
| `shape` | string | 器型 |
| `maker` | string | 制作人 |
| `position` | string | 窑位 |
| `formed_day` | integer | 成型日 |
| `sample` | boolean | 是否留样 |
| `reworked_from` | string | 返工前实物记录或空 |

显式引用：`kiln` → `kilns.id`。

## tests

分项检验，不含预先统计结论。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 检验 |
| `piece` | string | 实物 |
| `kind` | string | 外观或耐热 |
| `value` | number | 数值 |
| `unit` | string | 单位 |
| `known_day` | integer | 知悉日 |
| `state` | string | 有效或撤销 |

显式引用：`piece` → `pieces.id`。

## approvals

已有工艺批准，不代表全部工况。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 批准 |
| `process` | string | 工艺 |
| `shapes` | array | 器型 |
| `materials` | array | 材料 |
| `max_density` | number | 最高密度 |
| `effective_day` | integer | 起效日 |
| `state` | string | 状态 |

## orders

客户用途与允许的证据方式。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 订单 |
| `use` | string | 用途 |
| `qty` | integer | 件数 |
| `shape` | string | 器型 |
| `evidence` | string | 每批检验或批准加过程 |
| `min_heat_cycles` | number | 最低耐热 |
| `max_visual_grade` | number | 最大外观缺陷等级 |

## dispatches

实际出库事实不随批准撤回消失。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 出库 |
| `piece` | string | 实物 |
| `order` | string | 订单 |
| `day` | integer | 出库日 |

显式引用：`piece` → `pieces.id`；`order` → `orders.id`。
